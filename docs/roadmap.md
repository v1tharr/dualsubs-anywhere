# Dual Subtitles Anywhere — Roadmap

Цель проекта: рабочий инструмент для себя (двойные субтитры поверх любого видео в браузере, без скачивания) + презентабельный опенсорс-репозиторий под резюме. Баланс, не крен в одну сторону.

Формат работы: MVP сначала на ручной загрузке `.srt`, автопоиск через API — отдельным поздним этапом. Публикация в Chrome Web Store / Firefox Add-ons — опциональный финальный этап, не блокер для релизов.

## Этап 1 — MVP как WebExtension (Manifest V3)

Переупаковка текущей логики юзерскрипта в нормальное браузерное расширение.

- [ ] `manifest.json`: `content_scripts` (`matches: ["<all_urls>"]`), `permissions: ["storage", "activeTab"]`
- [ ] Перенос логики оверлея в `content_script.js`: поиск `<video>`, MutationObserver на лениво подгружаемые плееры, отрисовка двух текстовых блоков
- [ ] `chrome.storage.local` вместо `GM_setValue`/`GM_getValue`
- [ ] Плавающая кнопка **слева, по вертикали ~55–60% высоты видео** (не в углах — там нативные контролы плеера)
- [ ] Панель по клику: Load TOP / Load BOTTOM / чекбокс Show-Hide / Clear
- [ ] Хоткей `Alt+S` — toggle видимости
- [ ] Ручная загрузка `.srt` через `<input type=file>` — сохраняется как способ ввода навсегда, даже после Этапа 3 (API может не найти нужную дорожку или ошибиться с таймингом)
- [ ] Поддержка загрузки `.zip`-архива целиком (реальный кейс: сайты с сабами кладут по 10-20 файлов под разные релизы — DVDRip/BluRay/HDTV — с разным таймингом). Парсинг архива в браузере через JSZip, список найденных `.srt` с превью первых 2-3 реплик, выбор нужного файла прямо в панели без ручной распаковки
- [ ] Тестовая загрузка unpacked-расширения в Chrome (`chrome://extensions` → Load unpacked) — без стора

**Результат:** v0.1, расширение работает локально, две дорожки грузятся вручную.

## Этап 2 — Тесты и CI

- [ ] Вынести SRT-парсер в чистую функцию без DOM-зависимостей (`src/srt-parser.js`)
- [ ] Юнит-тесты (Jest или Vitest) на парсер:
  - BOM в начале файла
  - миллисекунды через запятую vs точку
  - пустые блоки / битые тайминги
  - пересекающиеся по времени реплики
- [ ] GitHub Actions workflow: lint + test на каждый push/PR
- [ ] Опционально: сборка `.zip`-артефакта на тег (`v*`) как черновик будущего релиз-пайплайна

**Результат:** v0.2, зелёный CI-бейдж в README, тестируемый код — конкретный пример для резюме.

## Этап 3 — Автопоиск субтитров (OpenSubtitles API)

- [ ] Регистрация API-ключа OpenSubtitles
- [ ] `background` service worker: поиск по названию (парсинг из `document.title` / URL страницы) либо по хешу видеофайла, если доступен
- [ ] UI: кнопка «Auto-find subtitles» в панели → список найденных вариантов → выбор языка для top/bottom отдельно
- [ ] Кэш найденных сабов по домену + названию, чтобы не дёргать API повторно
- [ ] Ручная загрузка остаётся доступной параллельно как альтернативный путь

**Результат:** v0.3, реальная автоматизация — то, что отличает проект от простого оверлея.
